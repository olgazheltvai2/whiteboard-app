Якщо хочете використовувати конкретний шкільний шрифт «Прописи» (наприклад, Propisi.ttf або Ukrajinski Propysy):
1. Перейменуйте файл шрифту на propysy.ttf
2. Завантажте його сюди, в папку fonts/ репозиторію whiteboard-app
3. Оновіть сторінку дошки (Ctrl+F5) — стиль «✍️ Прописний» автоматично підхопить ваш шрифт для вас і для всіх учнів!

Без цього файлу стиль «✍️ Прописний» одразу працює зі вбудованим рукописним шрифтом Marck Script (з повною підтримкою українських літер і, ї, є, ґ).
